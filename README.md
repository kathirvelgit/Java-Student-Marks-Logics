🎓 Student Marks and Grade Calculator – Java
A simple Java program that calculates student marks, determines grades, checks Pass/Fail status, and displays remarks using Java operators and conditional statements.

✨ Features
📝 Store student marks using variables.
➕ Add bonus marks using the += assignment operator.
🔀 Determine grades using if-else statements.
⚡ Check Pass/Fail status using the ternary operator.
🎯 Display remarks using a switch statement.
🖥️ Print marks, grade, result, and remarks in the console.

🛠️ Technologies Used
☕ Java	Programming language
💻 Visual Studio Code	Code editor
🔀 If-Else	Grade calculation
⚡ Ternary Operator	Pass/Fail determination
🎯 Switch Statement	Remark generation

📚 Java Concepts Covered
Variables and data types
Assignment operators (+=)
Conditional statements (if-else)
Ternary operator (?:)
Switch-case statements
